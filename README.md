# Local AI Chatbot

A local-first AI chatbot project designed to run on your machine.

## Overview

This repository is a starter workspace for building and running a local AI chatbot.
It is currently minimal and ready for you to expand with your app code.

## Project Structure

```text
local-ai-chatbot/
├── README.md
└── .gitignore
```

## Prerequisites

- Python 3.10 or newer
- Git

## Setup

1. Clone the repository:

```bash
git clone https://github.com/RushikeshPatil1373/local-ai-chatbot.git
cd local-ai-chatbot
```

2. Create a virtual environment:

```bash
python -m venv venv
```

3. Activate the virtual environment:

- Windows (PowerShell):

```powershell
venv\Scripts\Activate.ps1
```

- Windows (CMD):

```cmd
venv\Scripts\activate.bat
```

4. Upgrade pip:

```bash
python -m pip install --upgrade pip
```

## Git Ignore

The virtual environment folder is ignored in [`.gitignore`](.gitignore):

- `venv/`

This prevents local environment files from being pushed to the remote repository.
